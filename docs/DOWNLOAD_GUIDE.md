## 2. Скачивание проекта

### Способ 1: Git (рекомендуется)

```bash
git clone <URL-репозитория> "chimera project"
cd "chimera project"
```

### Способ 2: ZIP-архив

1. Скачайте ZIP-архив репозитория
2. Распакуйте в удобную папку (например `C:\chimera project`)
3. Откройте терминал в этой папке

## 3. Установка зависимостей

### Windows

**Вариант А — автоматический инсталлятор:**
```powershell
powershell -ExecutionPolicy Bypass -File installer\install_chimera.ps1
```

**Вариант Б — вручную:**

```powershell
# 1. Установить npm-зависимости (фронтенд + Electron)
npm install

# 2. Установить Python-зависимости (бэкенд)
pip install -r python-backend\requirements.txt
```

### macOS / Linux

**Вариант А — автоматический инсталлятор:**
```bash
bash installer/install_chimera.sh
```

**Вариант Б — вручную:**
```bash
npm install
pip3 install -r python-backend/requirements.txt
```

### Проверка установки

```bash
# Node.js
node --version    # должно быть v20+

# Python
python --version  # должно быть 3.11+

# ADB (опционально)
adb --version
```

## 4. Первый запуск

### Запуск приложения

```bash
npm run dev
```

Это запустит:
- **Vite** — фронтенд на `http://localhost:5173`
- **Electron** — десктоп-окно приложения
- **Python Backend** — автоматически на порту `17842`

### Авторизация

1. В открывшемся окне нажмите **«Получить код»**
2. Скопируйте 6-значный код
3. Откройте Telegram-бота **@Chiimeraa_bot**
4. Отправьте: `/start XXXXXX` (ваш код)
5. Приложение разблокируется автоматически

> Один код = один компьютер = один аккаунт.
> Код одноразовый и привязан к вашей установке.

## 5. Скачивание приложений на телефоны

### 5.1 Android — подготовка телефона

**Шаг 1: Включите режим разработчика**
1. Откройте **Настройки → О телефоне**
2. Нажмите **«Номер сборки»** 7 раз подряд
3. Появится сообщение «Вы стали разработчиком»

**Шаг 2: Включите USB-отладку**
1. **Настройки → Для разработчиков** (или «Система → Для разработчиков»)
2. Включите:
   - ✅ **Отладка по USB**
   - ✅ **Не выключать экран при зарядке** (рекомендуется)
   - ✅ **Разрешить установку через USB** (если есть)

**Шаг 3: Подключите телефон**
1. Подключите USB-кабель к компьютеру
2. На телефоне появится запрос — нажмите **«Разрешить»** (можно поставить галку «Всегда разрешать»)
3. Chimera автоматически установит агент (APK Deployer)

**Шаг 4: Проверка подключения**
```bash
adb devices
```
Должно показать ваш телефон со статусом `device`.

### 5.2 Установка приложений через ADB

**Instagram:**
```bash
# Скачайте APK с apkpure.com или apkmirror.com
adb install instagram.apk
```

**TikTok:**
```bash
adb install tiktok.apk
```

**Facebook:**
```bash
adb install facebook.apk
```

**Twitter (X):**
```bash
adb install twitter.apk
```

**Telegram:**
```bash
adb install telegram.apk
```

**VK:**
```bash
adb install vk.apk
```

> **Где скачивать APK:**
> - https://apkpure.com — все версии, без региональных ограничений
> - https://apkmirror.com — оригинальные APK из Google Play
> - https://apkcombo.com — альтернатива
>
> **Важно:** Скачивайте только оригинальные APK (не моды). Проверяйте подпись перед установкой.

### 5.3 Массовая установка

Если у вас несколько телефонов, используйте скрипт:

```bash
# Установить на все подключённые устройства
adb devices | grep device$ | awk '{print $1}' | while read serial; do
  adb -s "$serial" install instagram.apk
  echo "Установлено на $serial"
done
```

Или через интерфейс Chimera:
1. **Устройства → выберите телефон → «Установить агент»**
2. Агент Chimera установится автоматически и выдаст все нужные разрешения

## 6. Настройка Telegram-бота

### Запуск бота

1. Убедитесь, что приложение Chimera запущено (`npm run dev`)
2. В отдельном терминале:
   ```bash
   cd "C:\chimera project"
   py bot/chimera_bot.py
   ```
3. Бот запустится и выведет:
   ```
   CHIMERA TELEGRAM BOT v9.0
   API: http://localhost:17842
   ```

### Команды бота

| Команда | Описание |
|---------|----------|
| `/start КОД` | Авторизация по коду |
| `/verify КОД` | Альтернативная верификация |
| `/status` | Статус системы |
| `/devices` | Список устройств |
| `/accounts` | Список аккаунтов |
| `/screenshot` | Скриншот устройства |
| `/stats 7` | Статистика за N дней |
| `/post` | Создать публикацию |
| `/register` | Авто-регистрация аккаунта |
| `/schedule` | Планы публикаций |
| `/logs` | Последние логи |
| `/faq` | Частые вопросы |
| `/help` | Справка |

## 8. Решение проблем

### Приложение не запускается

```bash
# Проверьте, что порт 17842 свободен
netstat -an | findstr 17842

# Если занят, завершите процесс
taskkill /F /PID <PID>
```

### Телефон не подключается

**Чеклист:**
- ✅ USB-кабель поддерживает передачу данных (не только зарядку)
- ✅ USB-отладка включена
- ✅ На телефоне нажали «Разрешить»
- ✅ ADB установлен и в PATH
- ✅ Драйверы USB установлены (Windows)

**Установка драйверов (Windows):**
1. Скачайте Universal ADB Driver: https://adb.clockworkmod.com/
2. Или установите Android SDK Platform Tools

### Ошибка «npm не найден»

Установите Node.js: https://nodejs.org/

При установке обязательно поставьте галку **«Add to PATH»**.

### Ошибка «python не найден»

Установите Python: https://www.python.org/downloads/

При установке обязательно поставьте галку **«Add Python to PATH»**.

### Белый/чёрный экран в приложении

```bash
# Пересоберите фронтенд
npx vite build
npm run dev
```

### Бот не отвечает

1. Проверьте, что приложение Chimera запущено
2. Проверьте, что бот запущен (`py bot/chimera_bot.py`)
3. Проверьте токен бота в `bot/chimera_bot.py`
4. Проверьте подключение к интернету
