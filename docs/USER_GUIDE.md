# Методичка по эксплуатации Chimera

Полное руководство по использованию desktop-приложения **Chimera** для управления парком Android/iOS-устройств и автоматизации соцсетей.

---

## 1. Установка и первый запуск

1. Скачайте `Chimera-Setup.exe` со страницы релизов.
2. Запустите установщик. На последнем шаге автоматически скачивается Python 3.11 embedded + зависимости (~200 МБ) в `%LOCALAPPDATA%\Chimera\python`.
3. Дважды кликните по ярлыку **Chimera** на рабочем столе.

При первом запуске автоматически откроется **Мастер настройки** (второе окно), которое остаётся активным, пока вы не завершите все шаги.

---

## 2. Второе окно — Мастер настройки (OnboardingWizard)

Это модальное окно поверх главного интерфейса. Оно появляется при первом запуске и **остаётся активным** до тех пор, пока вы:

- не пройдёте все 5 шагов и не нажмёте **«Начать работу»**, либо
- не закроете его вручную, когда все ключевые шаги выполнены.

Шаги — в порядке следования, с возможностью «Назад»/«Далее»/«Пропустить» (кнопка «Пропустить» доступна с 3-го шага).

### Шаг 1 — Подключите телефоны

- Подключите Android- или iOS-телефоны по USB.
- Если на системе ещё нет ADB и/или libimobiledevice, в окне шага появится жёлтый блок с кнопкой **«Установить всё»** (или по отдельности «Только ADB»/«Только iOS»). Приложение скачает и распакует их в `%LOCALAPPDATA%\Chimera\tools\` автоматически — системный PATH не трогается.
- Нажмите **«Сканировать»** — приложение:
  - запустит `adb devices` и покажет все Android-устройства;
  - запустит `idevice_id -l` (libimobiledevice) и покажет все iOS-устройства;
  - автоматически добавит найденные устройства в базу.
- Если устройств нет, проверьте:
  - **Android:** установлен ли ADB (`adb --version`), разрешена ли отладка на телефоне;
  - **iOS:** установлен ли libimobiledevice (`idevice_id -l`), подтвердили ли вы «Доверять этому компьютеру» на iPhone.

### Шаг 2 — Включите USB-отладку (Android)

На каждом Android-телефоне:

1. Настройки → О телефоне → нажмите «Номер сборки» 7 раз.
2. Настройки → Система → Для разработчиков → «Отладка по USB».
3. Разрешите отладку при подключении (OK на телефоне).

Для iOS достаточно нажать **«Доверять»** при первом подключении.

### Шаг 3 — Добавьте аккаунты

Выберите платформу (instagram, tiktok, telegram, twitter, facebook, vk, youtube, linkedin, reddit, threads), введите логин и (опционально) пароль. Можно пропустить — аккаунты добавляются позже в разделе **«Соцсети»**.

### Шаг 4 — Загрузите фото

Введите название датасета, перетащите или выберите файлы, нажмите **«Загрузить»**. Датасет сохранится в `%APPDATA%\Chimera\datasets`.

### Шаг 5 — Готово

Сводка чек-листа. Нажмите **«Начать работу»** — мастер закроется и больше не появится (флаг `onboarding_completed=true` в настройках).

> Чтобы заново пройти мастер, сбросьте настройку `onboarding_completed` в разделе **Настройки → Общие** (или удалите запись из `chimera.db`).

## 3. Главное окно — разделы

Левое меню содержит следующие разделы.

### Устройства (Devices)

- Сетка карточек всех устройств. Каждая карточка показывает имя, платформу, статус (online/offline), заряд батареи, группу и флаг master.
- Кнопка **«Сканировать»** — перезапускает обнаружение через ADB/libimobiledevice.
- ПКМ по карточке — контекстное меню: назначить master, сменить группу, калибровать, снять скриншот, удалить.
- Скриншоты отображаются в режиме реального времени при онлайн-устройстве.

### Соцсети (Social Networks)

- Список аккаунтов по платформам.
- Добавление, редактирование, удаление аккаунтов.
- Привязка аккаунта к устройству и прокси.

### Датасеты (Datasets)

- Загрузка наборов фото/видео.
- Очистка метаданных (EXIF, GPS) — кнопка **«Очистить метаданные»**.
- Привязка датасета к конкретному устройству.
- Wear-map: карта износа (какие файлы уже использовались), чтобы не постить одно и то же.

### Генератор постов

- Создание постов на основе датасета и шаблонов.
- Выбор аккаунтов-получателей и расписания.

### Сообщения (Messages) / Комментарии / Приветствия / Автоответ

- Входящие сообщения, автоматические ответы, welcome-сообщения новым подписчикам.
- Правила срабатывания по ключевым словам, LLM-ответы (OpenAI-compatible endpoint из настроек).

### Мониторинг

- Графики активности аккаунтов, ошибок, статусов устройств.
- Heartbeat-события с устройств.

### Настройки

11 вкладок: Общие, Анализ аккаунтов, Автоответ, Приветствия, Прогрев, Telegram, Прокси, Антидетект, Метаданные, Бэкапы, О программе. Ключевые:

- **Общие** — язык интерфейса, автозапуск, сворачивание в трей, размер ячеек в сетке устройств.
- **Автоответ** — endpoint LLM, API-ключ, модель, температура.
- **Telegram** — bot token и chat ids для уведомлений.
- **Прокси** — список прокси, проверка доступности.
- **Антидетект** — профиль (samsung/pixel/…), ротация.
- **Бэкапы** — автобэкап в `%APPDATA%\Chimera\backups`, время, срок хранения.

## 4. Типовые сценарии

### 4.1. Подключили новый телефон

1. Откройте **Устройства** → **«Сканировать»**.
2. Если устройство не появилось:
   - Android: `adb devices` в терминале должно его показывать;
   - iOS: `idevice_id -l` должно возвращать UDID.
3. Карточка появилась → ПКМ → назначьте группу и, при необходимости, master.

### 4.2. Добавили новый датасет фото

1. **Датасеты** → **«Загрузить»** или через мастер.
2. (Опционально) **«Очистить метаданные»** перед использованием.
3. Привяжите к устройству, если фото должны публиковаться только с него.

### 4.3. Настроили автоответ

1. **Настройки → Автоответ** — укажите LLM endpoint, ключ, модель.
2. **Сообщения** — включите правило автоответа для нужных аккаунтов.

### 4.4. Запустили прогрев

1. **Настройки → Прогрев** — базовое число устройств, адаптивный режим.
2. **Мониторинг** — следите за графиком активности.

## 5. Расположение данных

- **Windows:** `%APPDATA%\Chimera`
- **macOS:** `~/Library/Application Support/Chimera`
- **Linux:** `$XDG_DATA_HOME/Chimera`

Подпапки: `datasets/`, `cleaned/`, `exports/`, `backups/`, файл `chimera.db` (SQLite WAL). Переопределяется переменной `CHIMERA_DATA_DIR`.

## 6. Диагностика проблем

| Симптом | Что проверить |
| --- | --- |
| «Network error» при загрузке фото | Python-сайдкар на `127.0.0.1:17842` живой? Откройте `http://127.0.0.1:17842/health`. |
| Устройство не найдено | Android: `adb devices`. iOS: `idevice_id -l`. Драйверы / USB-кабель / «Доверять компьютеру». |
| Настройки не сохраняются | Права на `%APPDATA%\Chimera\chimera.db`. Проверьте логи сайдкара. |
| Мастер не открывается | В Настройках снимите `onboarding_completed=false` или удалите соответствующую строку в `settings`. |
| Сайдкар падает в dev | Проверьте, что `py` указывает на реальный Python 3.11, а не на Microsoft Store alias (`py -0`). |

## 7. Для разработчиков

```bash
git clone <repo-url> chimera
cd chimera
npm install
pip install -r python-backend/requirements.txt
npm run dev
```

- Vite на `http://localhost:5173`, Electron main → `dist-electron/`, Python sidecar на `127.0.0.1:17842`.
- Готовность сайдкара: `GET /health`.
- Сборка: `npm run dist:win` или `powershell -ExecutionPolicy Bypass -File scripts/build.ps1`.

## 8. Сочетания клавиш

- `Ctrl + ,` — открыть Настройки.
- `Ctrl + K` — глобальный поиск.
- `Ctrl + Shift + D` — перейти к устройствам.
- `Esc` — закрыть модальное окно (кроме мастера настройки на первом запуске).
